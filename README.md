# PyRAPSS
PyRAPSS modifies PSS®E steady-state and dynamic power system models to represent hydropower generators at user-specified reservoir water levels. It updates maximum generation limits using two calculation methods, validates the modified model with a load flow, and outputs simulation-ready files.
